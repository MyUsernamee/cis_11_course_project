# CIS-11 Course Project

This is a course project for CIS-11 (Assembly Programming in LC-3).

# Documentation

The project prompt is in [PROMPT.md](docs/PROMPT.md).
The design and considerations and documentation is in [docs/](./docs/).

# Usage

To aid with development, we created a simple python script to do basic 
macro like expansions on `.PUSH`, and `.POP`. These simply push / pop all
the registers (outside of R0, R6 and R7) to the stack.

```
Simply load frequency_counter.post.obj into any LC-3 capable simulator.
The program will prompt for a name and output the number of occurences
for each character.
```
